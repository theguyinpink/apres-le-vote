# Intégration des illustrations quotidiennes

Ce dossier contient :
- `public/illustrations/daily/...` : toutes les illustrations quotidiennes disponibles
- `lib/parties.ts` : les chemins `image` déjà liés pour chaque entrée `daily`

## Pour intégrer
1. Copier le contenu de `public/illustrations/daily/` dans votre projet au même emplacement.
2. Remplacer `lib/parties.ts` par la version fournie ici.
3. Relancer le serveur de développement.

## État
Les illustrations sont liées pour :
- les 6 premiers partis initiaux
- vague 1 : Horizons, Nouvelle Énergie, Nous France, Génération Écologie, Lutte Ouvrière, Debout la France, Les Patriotes, UPR, Solution démocratique, Équinoxe
- vague 2 : MoDem, PCF, UDR, Debout !, L'APRÈS, UDB, Reconquête, Place publique

Reste à faire si besoin :
- La Convention
- La France humaniste
