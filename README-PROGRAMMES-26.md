# Après le vote — 26 dossiers programmatiques

Cette version contient les 26 partis/mouvements de la liste principale en `dossierStatus: "published"`.

Dernière vague ajoutée :
- Solution démocratique
- Équinoxe
- Mouvement démocrate
- Parti communiste français
- Union des droites pour la République
- Debout !
- L’APRÈS
- Union démocratique bretonne
- Reconquête !
- Place publique
- La Convention
- La France humaniste

Chaque mouvement dispose :
- de sa fiche dans `lib/parties.ts` ;
- d’un corpus programmatique dans `lib/party-programs.ts` ;
- d’une projection favorable dans `lib/projections.ts` ;
- de son logo dans `public/logos`.

Les fiches signalent explicitement lorsqu’un programme présidentiel 2027 final n’est pas encore disponible et indiquent le corpus provisoire utilisé.
