# Déploiement Vercel

Ce dossier est la version Vercel de Après le vote.

- Framework : Next.js
- Build command : `npm run build` (`next build`)
- Domaine prévu : `apreslevote.maisonclm.fr`
- Umami : configuré uniquement pour ce domaine

Dans Vercel, importez le dépôt, laissez le preset **Next.js** et les réglages de build par défaut.
